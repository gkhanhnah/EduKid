Design a modern, user-friendly web application UI for a primary school (Grade 1) classroom management system.

## 🎯 Target Users:

* Teachers (main users)
* Parents (secondary users)

## 🎨 Design Style:

* Friendly, playful, and clean (suitable for children and teachers)
* Soft rounded corners, large buttons
* Use bright but soft colors (not too harsh)

## 🌈 Color Palette:

* Primary: #4F46E5 (soft indigo)
* Secondary: #22C55E (green - positive feedback)
* Warning: #F59E0B (yellow/orange)
* Danger: #EF4444 (red)
* Background: #F9FAFB (light gray/white)
* Text: #111827 (dark gray)

## 🔤 Typography:

* Font: Inter or Poppins
* Large font sizes for readability
* Use icons + text (important for quick interaction)

---

## 📱 Pages to Design:

### 1. Login Page

* Simple login form (email + password)
* Friendly illustration (kids/classroom)
* “Login as Teacher / Parent”

---

### 2. Teacher Dashboard

* Sidebar:

  * Dashboard
  * Students
  * Behavior Tracking
  * Games
  * AI Lesson Generator
  * Messages
* Main area:

  * Class overview (total students, today behavior summary)
  * Quick actions

---

### 3. Student Management Page

* Grid or list of student cards:

  * Avatar (cartoon style)
  * Name
  * Status indicator
* Button: “Add Student”

---

### 4. Behavior Tracking Page (MOST IMPORTANT)

* Display all students in grid
* Each student card includes:

  * Name
  * 4 big action buttons:

    * 👍 Good (green)
    * 👎 Bad (red)
    * 😴 Sleepy (yellow)
    * ⭐ Active (blue)
* Real-time feedback animation when clicked
* Show today’s behavior summary

---

### 5. Behavior History Page

* Table or timeline:

  * Student name
  * Behavior type (icon + color)
  * Timestamp
* Filter by date

---

### 6. Game-Based Learning Page

* Grid of mini games:

  * Alphabet game
  * Number counting
  * Matching game
* Each game card:

  * Thumbnail
  * Difficulty level (Easy / Medium / Hard)
* “Start Game” button

---

### 7. Game Play Screen

* Full-screen mode
* Large buttons, colorful UI
* Interactive elements (drag-drop, click answers)
* Progress bar (level progression)

---

### 8. AI Lesson Generator Page

* Input box:

  * “Enter topic (e.g., Teach letter A)”
* Button: Generate
* Output:

  * Slide preview (title + content)
  * Suggested exercises

---

### 9. Messaging Page (Teacher ↔ Parent)

* Chat UI similar to Messenger
* Left: conversation list
* Right: chat messages
* Support sending:

  * Text
  * Images

---

### 10. Parent Dashboard

* Child overview:

  * Behavior summary (icons)
  * Daily report
* Timeline of activities
* Messages from teacher

---

## ✨ UX Requirements:

* Everything must be clickable in 1–2 steps
* Big buttons for fast classroom usage
* Minimal typing required
* Use icons heavily for quick recognition

---

## 🎯 Output Requirement:

* Design all pages in a consistent design system
* Include components:

  * Buttons
  * Cards
  * Modals
  * Tables
* Use auto layout and responsive design
